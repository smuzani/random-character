AI Usage Disclosure

Last Updated: May 19, 2025


AI Content in This Tool

In accordance with platform requirements like Steam and itch.io, we want to be transparent about how artificial intelligence is used in Random Character Generator.

What is AI in This Context?

When platforms ask about "AI" today, they're specifically referring to modern generative AI (aka GenAI) tools like ChatGPT, Midjourney, or Stable Diffusion. These are different from traditional procedural generation techniques that have been used in games for decades.

Our core engine uses procedural generation - a traditional programming technique that creates content using predefined rules and randomization. This is NOT considered "AI" under many platform guidelines.

What Uses Generative AI

We use modern generative AI for:

  • Text Descriptions: Converting raw character data into readable descriptions. The engine generates traits such as "brave" and "intelligent" and GenAI writes a pre-written description.
  • Development Assistance: Some of our code and UI elements were written with GenAI assistance

What Doesn't Use AI

These core components use traditional procedural generation or curated datasets:

  • Core Generation Engine: Uses traditional procedural generation techniques
  • Names: Generated using the Moby Word List by Grady Ward (public domain)
  • Character Traits & Personalities: Based on:
    • The 36 Dramatic Situations (public domain)
    • TV Tropes (used with attribution)
  • Basic Templates: Hand-crafted content structures

Changes to AI Usage

If we make significant changes to how we use AI in our tool, we'll update this disclosure and the date at the top of this page.
